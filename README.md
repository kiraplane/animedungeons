# Anime Dungeons Wiki

English Roblox guide site for [animedungeons.wiki](https://www.animedungeons.wiki).

The site covers code status, class decisions, dungeon progression, loot
upgrades, heroes, spells, verified links, and the boundary between the current
and unavailable old Place. The homepage uses a compact media hero and every
content page has sticky desktop wiki navigation plus a mobile menu.

## Local development

```bash
pnpm install
pnpm dev
```

Validate with `pnpm lint`, `pnpm exec tsc --noEmit`, `pnpm next:build`, and `pnpm build`.
