当前公开竞品以代码页和薄型链接页为主，尚未形成稳定的系统型英文 Wiki。本站首发重点是：严格区分新旧 Place、把代码“官方确认”和“社区上报”分层，并用 classes、dungeons、gear、spells、heroes 与五条原创玩家路线承接高意图查询。

不发布无可比数据支持的完整 tier list、掉率表或数值数据库；不把旧 Place 的代码、创作者和奖励迁移到当前 1B Studio 体验。
